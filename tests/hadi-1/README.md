## Что не сходится, нужно решить

1. ~~Консультация и диагностика~~: решено, **консультация = бесплатный урок-диагностика**. В таблице и на странице можно писать любым из двух названий.
2. **Валюта.** Таблица в $, кабинет в EUR.
3. **Другая воронка.** Прошлые результаты получены на сайт и лид-форму, а тест идёт на страницу консультации. Сравнивать цену лида с прошлой нужно осторожно.
4. **Текст.** В новом черновике две непроверенные фразы: «40 минут» и «ни к чему не обязывает».
5. **Тексты в постах.** У КОНЯ и ТЫ Я СОЗВОН текст лежит в посте Facebook, через API его не поменять. Для теста надо создать новые объявления с текстом.
