# Платформа Espachicas: структура и дерево функций

Документ собран по итогам обсуждения и соответствует прототипу Espachicas Campus (версия 4).
Прототип: https://claude.ai/artifact/Maadg6WEz4bHe3wtpaNM9k

## 1. Термины

| Термин | Что это |
|---|---|
| **Тренинг** | Продукт школы, например «Разговорись» или «Español A2». Слово «курс» не используем. |
| **Модуль** | Тема внутри тренинга на несколько недель. Группирует уроки. |
| **Урок** | Материалы для изучения. Один тип урока, без деления на «урок» и «тренинг». |
| **Домашнее задание (ДЗ)** | Часть урока. Отдельная сущность со своим конструктором, привязана к одному уроку. |
| **Группа** | Класс: люди, преподаватель, расписание. Принадлежит тренингу. |
| **Занятие** | Живая встреча группы (дата, время, Zoom, посещаемость). Ссылается на модуль или урок тренинга, но не входит в материал. |
| **Доступ** | Связь «ученик + тренинг + срок». |

## 2. Что является частью чего

```
Тренинг
├─ МАТЕРИАЛ (что осваивают, не зависит от дат)
│  └─ Модуль
│     └─ Урок
│        ├─ Блоки урока (видео, текст, аудио, изображение, PDF, ссылка, упражнение LearningApps, доска Miro)
│        └─ Домашнее задание
│           └─ Блоки ДЗ (инструкция, материалы, задания для ученика)
│
├─ ГРУППЫ (кто учится)
│  └─ Группа (преподаватель, ученики, дата старта, расписание)
│     └─ Занятие (живая часть, ложится поверх материала)
│        ├─ Дата и время
│        ├─ Zoom: ссылка и запись
│        ├─ Тема = ссылка на модуль или урок материала (или свободная тема)
│        └─ Посещаемость (отметка на каждого ученика)
│
└─ ДОСТУПЫ (кто купил и до какого числа)
```

Связи на пересечениях:

| Сущность | Принадлежит | Ссылается на |
|---|---|---|
| Модуль, урок, блоки, ДЗ | Тренинг (материал) | — |
| Группа | Тренинг | преподаватель |
| Ученик в группе | Группа | — |
| Занятие | Группа | модуль или урок материала |
| Посещаемость | Занятие | ученик |
| Сдача ДЗ | ДЗ | ученик |
| Доступ | Тренинг | ученик |
| Цель, дневник цели, достижения | Тренинг | ученик |
| Комментарий преподавателя | Ученик в группе | преподаватель |
| Чек-ин состояния | Ученик (общий) | при низкой оценке создаёт задачу для Отдела заботы |

## 3. Правила

- Один ученик может иметь доступ к нескольким тренингам, но в каждом тренинге состоит максимум в одной группе.
- Одному тренингу соответствует несколько групп с разными расписаниями и преподавателями.
- Тренинг может создать и опубликовать и преподаватель, и администратор. Права на тренинги у них равные.
- Преподаватель видит только свои тренинги (созданные им или те, где у него есть группа) и свои группы. Администратор видит всё.
- Урок может быть стоп-уроком: следующие уроки закрыты, пока ученик не сдаст ДЗ к нему (если ДЗ нет, пока не отметит урок пройденным).
- Доступ можно задать на тренинг, модуль и урок: платный, демо (открыт всем), скрыт. Срок доступа задаётся на тренинге.
- Срок доступа отсчитывается от даты выдачи. После окончания материалы закрываются автоматически. Демо-уроки остаются открытыми.
- ДЗ проверяется автоматически (пропуски, вопросы, сопоставление) и/или преподавателем (письменный ответ, голос, файл). Проверяет преподаватель группы ученика.
- Занятие хранится в группе. Один и тот же материал в разных группах ложится на разные даты.

## 4. Дерево ученика

```
Ученик
├─ Вход / регистрация
├─ Мои тренинги
│  └─ Тренинг (доступен / срок закончился / не оплачен)
│     ├─ Обзор
│     │  ├─ Кольцо прогресса, уроки, ДЗ, посещаемость, серия дней подряд
│     │  ├─ Модули (прогресс по каждому)
│     │  ├─ Карта активности за 12 недель
│     │  ├─ Список домашних заданий со статусами
│     │  ├─ Маршрутная карта (старт → модули → цель → следующий уровень)
│     │  └─ Ближайшие занятия
│     ├─ Материал
│     │  └─ Модуль → Урок
│     │     ├─ Блоки урока
│     │     └─ Домашнее задание
│     │        ├─ Условия: срок, проходной балл, попытки, способ проверки
│     │        ├─ Задания: пропуски, вопрос с вариантами, сопоставление,
│     │        │          письменный ответ, голосовой ответ, файл или фото
│     │        └─ Результат: принято / на проверке / доработать, обратная связь, «Пройти ещё раз»
│     ├─ Занятия (ближайшие и прошедшие; Zoom, материал занятия, запись, моя посещаемость)
│     ├─ Группа (преподаватель, одногруппники, средний прогресс группы)
│     └─ Цель
│        ├─ Цель по SMART, точка А и точка Б
│        ├─ Дневник цели (актуальна / переписать)
│        ├─ Дневник достижений
│        └─ Состояние недели: чек-ин и история
├─ Расписание (все занятия моих групп)
├─ Профиль (данные, пароль, Telegram, вид на телефоне)
└─ Чек-ин недели на главной
```

## 5. Дерево преподавателя

```
Преподаватель
├─ Сегодня (сводка по всем моим группам)
│  ├─ ДЗ ждут проверки
│  ├─ Кому нужна поддержка (причина, карточка, «В заботу»)
│  ├─ Ближайшие занятия
│  └─ Прогресс моих групп
├─ Мои тренинги
│  ├─ + Создать тренинг (черновик, публикует преподаватель или админ)
│  └─ Тренинг
│     ├─ Обзор (прогресс по модулям, активные ученики по неделям, состояние учеников, кому нужна поддержка)
│     ├─ Материал
│     │  └─ Модуль → Урок
│     │     ├─ Конструктор урока
│     │     ├─ Конструктор ДЗ
│     │     └─ Порядок, стоп-урок, доступ, копия урока вместе с ДЗ
│     ├─ Группы (только мои)
│     │  ├─ + Создать группу
│     │  └─ Группа
│     │     ├─ Ученики (прогресс, посещаемость, активность, ДЗ, статус; матрица «ученик × урок»; добавить ученика)
│     │     ├─ Занятия (расписание, + новое, повтор на 4 недели)
│     │     │  └─ Занятие (дата, время, материал, тема, Zoom, запись, заметки, посещаемость)
│     │     ├─ Журнал (посещаемость: занятия × ученики)
│     │     ├─ Проверка ДЗ этой группы
│     │     └─ Настройки (название, старт, расписание, участники)
│     ├─ Доступы (ученики моих групп, выдать, отозвать, продлить, назначить группу)
│     └─ Настройки (название, уровень, срок доступа, публикация)
├─ Проверка ДЗ (сводный вид по всем моим группам)
└─ Карточка ученика (панель справа)
   ├─ Прогресс по тренингам, ДЗ, посещаемость
   ├─ Карта активности
   ├─ Доступы
   └─ История, комментарии, «Передать в заботу»
```

## 6. Дерево администратора

```
Администратор
├─ Тренинги
│  ├─ + Создать тренинг
│  └─ Тренинг (то же, что у преподавателя, но по всем группам и всем ученикам)
│     ├─ Обзор
│     ├─ Материал
│     ├─ Группы
│     │  └─ Группа → Ученики, Занятия, Журнал, Проверка ДЗ, Настройки
│     ├─ Доступы
│     └─ Настройки
├─ Люди
│  ├─ Ученики (поиск, фильтр по доступам, тренинги и группы, активность, статус) → карточка
│  │  ├─ Профиль (имя, почта, Telegram)
│  │  ├─ Доступы по тренингам
│  │  └─ «Открыть кабинет глазами ученика»
│  └─ Преподаватели (группы, тренинги, число учеников)
├─ Очередь
│  ├─ Цифры: активные ученики, доступы истекают, ДЗ ждут проверки, задачи для заботы
│  ├─ Требует внимания: продлить доступ, взять задачу в работу, опубликовать черновик
│  ├─ Активные ученики по неделям
│  ├─ Состояние учеников
│  └─ Прогресс по тренингам
└─ Данные и безопасность
   ├─ Экспорт (ученики, тренинги, группы, занятия, уроки, результаты, доступы)
   ├─ Резервные копии (создать, восстановить)
   ├─ Независимость от разработчика (репозиторий, домен, аккаунты, документация)
   ├─ Права доступа по ролям
   └─ Проверка доступности из РФ и ЕС (в прототипе демо)
```

## 7. Конструкторы

### Конструктор урока (без кода)
```
Урок
├─ Название, статус (черновик / опубликован)
├─ Редактор / Предпросмотр
├─ Блоки: видео, текст, аудио, изображение, PDF-файл, ссылка,
│         упражнение LearningApps, интерактивная доска (импорт из Miro)
├─ Порядок блоков, удаление
└─ Домашнее задание урока: открыть конструктор или создать
```

### Конструктор домашнего задания (без кода)
```
Домашнее задание
├─ Название, статус, привязка к уроку
├─ Настройки: срок сдачи (дней после урока), проходной балл, число попыток,
│             способ проверки (автоматически / преподаватель / вместе)
├─ Редактор / Предпросмотр
├─ Пояснения и материалы: инструкция, видео, аудио, изображение, PDF, ссылка
└─ Задания для ученика
   ├─ Заполнить пропуски (предложения, варианты, верный вариант; автопроверка)
   ├─ Вопрос с вариантами (один верный; автопроверка)
   ├─ Сопоставление (пары; автопроверка)
   ├─ Письменный ответ (проверяет преподаватель)
   ├─ Голосовой ответ (проверяет преподаватель)
   └─ Файл или фото (проверяет преподаватель)
```

## 8. Связи между ролями

```
Ученик сдаёт ДЗ                 → автопроверка сразу / преподаватель проверяет → ответ ученику
Ученик отмечает «Тяжело»        → задача для Отдела заботы → видна админу в «Очереди»
Преподаватель «Передать в заботу» → задача для Отдела заботы
Админ или преподаватель отзывает доступ → у ученика тренинг закрывается
Преподаватель или админ публикует материал → ученик видит его
Занятие группы ссылается на урок → ученик открывает материал занятия из расписания
```

## 9. Права ролей

| Действие | Ученик | Преподаватель | Админ |
|---|:-:|:-:|:-:|
| Проходить уроки, вести цель | да | да | да |
| Журнал группы и посещаемость | нет | да (свои группы) | да |
| Проверять задания | нет | да | да |
| Редактировать уроки и ДЗ | нет | да | да |
| Создавать тренинги, группы и занятия | нет | да | да |
| Публиковать материал тренинга | нет | да | да |
| Выдавать и отзывать доступ | нет | да | да |
| Люди, очередь и экспорт данных | нет | нет | да |
| Резервные копии и безопасность | нет | нет | да |

## 10. Принятые решения по умолчанию

- Урок открывается ученику без привязки к дате занятия. Правило «открывать материал после занятия» в структуре не заложено.
- Срок доступа отсчитывается от даты выдачи.
- Срок сдачи ДЗ считается от урока (N дней после урока).
- «Забота» отдельной ролью не является: задачи накапливаются в очереди администратора.
- Занятие хранится только в группе (без шаблона на уровне тренинга).
- Zoom: в занятии заложены поля (ссылка, запись, посещаемость вручную). Подключение Zoom API следующим этапом.

## 11. Открытые вопросы

1. Сводный раздел «Проверка ДЗ» у преподавателя дублирует вкладку внутри группы. Оставляем или убираем?
2. Нужно ли правило «открывать урок после занятия» и в каком виде (сразу / после занятия / по дате)?
3. Вход в уже идущую группу: видит ли новый ученик пройденные занятия и записи, можно ли переходить между группами?
4. Нужна ли отдельная роль «Забота» с кабинетом (карточки, чек-ины, задачи) или всё остаётся в AlfaCRM?
5. Бывает ли несколько преподавателей или куратор в одной группе?
6. Бывают ли занятия для всех учеников тренинга (вебинар) и тренинги без групп (только самостоятельная учёба)?
7. Статусы ученика в тренинге (активен, на паузе, завершил, отчислен) и действия по ним (передача в повторные продажи).
8. Уведомления: что и куда отправляем (напоминание о занятии, срок ДЗ, ответ преподавателя, продление доступа).
9. Обязательность цели и дневников, и кто их видит (только преподаватель или ещё и забота).
10. Тесты как отдельная сущность (пока тест это вопросы внутри ДЗ).
